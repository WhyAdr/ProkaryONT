Date: 2026-06-25
Author: Antigravity (AI coding assistant)

This changelog records the Stage 2/3 pipeline split, full STEP renumbering
(STEP 1-17 across the core pipeline), and the preprocessing diagnostics
overhaul: Fastcat/Porechop_ABI/SNIKT diagnostics in Stage 1; optional
Porechop_ABI trim, SNIKT re-assessment, and optional Chopper end-trim in
Stage 2; Fastplong demoted to QC-reporting only (its Q-score formula uses a
flat arithmetic Phred mean with integer truncation, confirmed via source
read to diverge from Seqkit/Chopper's probability-space mean — not used
for filtering). RagTag removed pending a dedicated post-assembly script.

Summary of Changes
------------------

1. 02_filter_assemble.sh → 02_preprocess_filter.sh + 03_autocycler_assemble.sh (Pipeline Split)
   - Split the monolithic filter+assemble script into two independently
     runnable stages, handed off via filtered_input.fastq.gz.
   - Consolidated the previously-duplicated genome-size recovery logic into
     one block (now STEP 9a).
   - Removed RagTag scaffolding entirely (was tail of the old script) —
     deferred to a future dedicated script; --ragtag now logs an explicit
     no-op warning instead of silently doing nothing.
   - Renumbered every in-file STEP label across the core pipeline (STEP
     1-17, see major_overhaul_implementation_plan_REFINED_v2.md §4 for the
     full map).

2. 01_qc_estimate.sh (Preprocessing Diagnostics)
   - Added Fastcat (per-file stats + histograms), Porechop_ABI ab-initio
     discovery scan, and SNIKT baseline contamination report as STEP 2,
     all hard dependencies (require_tool) of this script going forward.

3. 02_preprocess_filter.sh (Trimming additions)
   - Added optional Porechop_ABI adapter trimming (STEP 4) and optional
     Chopper end-trimming via --trim-approach (STEP 6), both off by
     default and meant to be enabled only after reviewing Stage 1/Stage 2
     SNIKT and Porechop_ABI diagnostics.
   - Added SNIKT re-assessment (STEP 5) and Fastplong QC reporting (STEP 8,
     report-only — see rationale above).

4. run_all.sh / prokaryont.sh (Renumbering)
   - run_all.sh now orchestrates Stages 1-4. prokaryont.sh usage text and
     taxonomy/annotate dispatch updated for the 05_/06_ renumbering.

Date: 2026-06-21
Author: WhyAdr & Antigravity AI Pair Programmer

This changelog records the bug fixes and refinements implemented across the pipeline scripts to address logic errors, performance constraints, and robustness issues.

Summary of Changes
------------------

1. 00_setup.sh (Foundation Utilities)
   - Changed `log_error` exit behavior from soft return to a hard `exit 1` to prevent continuation under `||` chains or function scopes.
   - Replaced static `GZIP_BIN` export with dynamic `get_gzip_cmd()` function to properly support custom thread allocations at execution time.
   - Restricted `load_config` keys strictly to lowercase snake_case (`^[a-z][a-z0-9_]*$`) to protect system environment variables from configuration overrides.
   - Enhanced dry-run command logging format using `printf %q` to preserve shell-escaped command structure.
   - Hardened log file initialization by checking write permission and falling back to `/dev/null` on failure.

2. 01_qc_estimate.sh (QC & Genome Estimation)
   - Integrated dynamic GZIP command mapping.
   - Fixed `free -g` parsing of available memory by adding a fallback column check.
   - Reordered `meryl count` arguments to correctly support version 1.4+.
   - Added heuristic comment for the genome size calculation weighting.
   - Guarded `raven_size` calculation in dry-run mode to prevent parsing stale assembly files.
   - Fixed carriage return accounting (`tr -d '\r\n'`) to prevent CRLF line endings from inflating computed sizes.
   - Cleaned up intermediate Raven GFA files after size computation to conserve disk space.
   - Supported a configurable `lrge_seed` parameter (default 123) for reproducibility.
   - Documented the step gap (Step 2 resides in `02_filter_assemble.sh`).

3. 02_filter_assemble.sh (Assembly & Filtering)
   - Front-loaded `read_type` validation.
   - Restored detailed multi-line comment rationale on Seqkit quality filtering.
   - Added `pipefail` to Filtlong and Minimap2 commands to catch silent pipeline crashes.
   - Overhauled GNU Parallel exit code checks to correctly distinguish and report OOM (signal) kills and count job errors from joblogs.
   - Replaced temporary file creation for ETE3 checking with direct Python heredoc execution.
   - Updated ETE3 leaf parser to correctly strip quotes and parse arbitrary leaf name suffixes.
   - Added `nullglob` checks for combine GFAs to handle empty cluster cases gracefully.
   - Added pipeline fail fallback to Seqkit stats parsing.
   - Replaced slow `samtools depth` parsing with efficient `samtools coverage` summaries.
   - Aligned job-building loops indentation to match else scope.
   - Fixed carriage return accounting (`tr -d '\r\n'`) in curation diagnostics.
   - Passed `--nice 19` option explicitly to parallel itself rather than using the `nice` utility.

4. 03_polish_orient.sh (Polishing & Reorientation)
   - Added dynamic GZIP setup and pipefail logic.
   - Added dry-run guard to renaming operations.
   - Removed CPU-centric `--infer-threads` flag from Dorado polish for GPU polishing runs.
   - Implemented re-run idempotency checks to skip Dnaapler when final outputs are present.
   - Replaced fragile tab escaping regex in SAM RG unification with C-string quoting (`$'...'`).
   - Standardized use of `samtools quickcheck -u` across all alignments validation checks.
   - Copied final reoriented assemblies to output instead of symlinking.

5. run_all.sh (Master Orchestrator)
   - Forwarded `skip_curation` systematically to all child scripts via `common_flags`.

Date: 2026-05-22
Author: Antigravity AI Pair Programmer

This changelog records the recent enhancements made to the Prokaryote Genome Assembly pipeline (ProkaryONT) scripts to capture extensive runtime diagnostics, optimize input statistics handling, and surface critical polishing and reorientation details.

Summary of Changes
------------------

1. 02_filter_assemble.sh (Assembly & Diagnostics Upgrades)
   - Standardized Consensus Path: Set default autocycler_consensus output path to point directly to `autocycler_out/consensus_assembly.fasta` in all stages rather than moving it to the root path.
   - Autocycler Cluster Diagnostics: Captured standard out/error logs of `autocycler cluster` to parse and output clean cluster distances, QC pass/fail status, and reasons using `awk` to the pipeline log.
   - Comprehensive Per-Cluster Metadata Logging: Introduced `autocycler_out/cluster_metadata.tsv` which compiles extensive per-cluster resolution metrics during the trim & resolve loop:
     * Overlaps trimmed (circular start-end and hairpin)
     * MAD filtering parameters (median, MAD value, allowed range)
     * Contig retention status (kept vs. excluded count)
     * Bridge resolution details (anchors, unique bridges, conflicting bridges)
     * Final unitig counts and total resolved assembly length
   - Combined Assembly Logging: Captured `autocycler combine` console logs to print combined assembly topology (circularity and length statistics) automatically.
   - Smart Metrics Prepending: Refactored the update step of `metrics.tsv` to detect and safely fill in existing input read metric columns (e.g. read count, bases, N50) instead of blindly prepending them, ensuring compatibility with newer versions of Autocycler.
   - Combined Contig Characteristics Report: Added Step 4q which merges per-cluster assembly metrics from `cluster_metadata.tsv` with depth coverage from `contig_depths.tsv` into a unified `contig_characteristics.tsv` report.
   - Enhanced Contig Summary Logging: Outputs a high-fidelity tabular summary in pipeline log for all contigs, flagging high-copy-number replicons with relative depth > 1.5×.

2. 03_polish_orient.sh (Reorientation Diagnostics)
   - Dnaapler Logging Integration: Added parsing logic to automatically search the `dnaapler_out/*.log` directory.
   - Diagnostic Surfacing: Extracts and prints reorientation hits, rotation coordinates, and start genes (such as dnaA, repA, terL) directly to console/pipeline run logs, making rotation decisions transparent.

3. run_all.sh (Master Orchestrator Standardization)
   - Unified Consensus Filepath: Updated Stage 3's arguments to invoke `autocycler_out/consensus_assembly.fasta` instead of the root-level path.
   - Key Outputs summary: Updated the final stage completion report to list `autocycler_out/consensus_assembly.fasta` as the primary consensus artifact.
